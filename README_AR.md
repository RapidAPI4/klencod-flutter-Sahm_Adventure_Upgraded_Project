# سهم – مغامرة الغابة | النسخة المطورة

مشروع Godot 4 للعبة مغامرات وقتال ثنائية الأبعاد، جاهز للفتح والتجربة والتطوير.

## المميزات
- تحكم باللمس على الهاتف وعصا افتراضية للحركة.
- زر هجوم مع مدى للضربة ووقت انتظار بسيط.
- ست موجات متدرجة الصعوبة.
- زعيم يظهر في كل موجة ثالثة.
- نقاط وكنوز وصحة، مع استعادة جزء من الصحة بين الموجات.
- شاشة فوز وخسارة وإعادة اللعب.
- رسومات مرسومة برمجياً ولا تحتاج ملفات صور خارجية.

## تشغيل المشروع
1. ثبّت Godot 4.3 أو أحدث: https://godotengine.org/
2. فك الضغط وافتح Godot.
3. اختر Import ثم ملف `project.godot`.
4. اضغط تشغيل.

## تصدير Android
1. في Godot افتح Editor > Manage Export Templates وثبّت القوالب المطابقة.
2. جهّز Android SDK وJDK وفق دليل Godot الرسمي.
3. من Project > Export أضف Android preset.
4. صدّر APK للتجربة على هاتفك.
5. للنشر على Google Play ستحتاج إعداد AAB موقّعاً، أيقونة، لقطات شاشة، وصفاً، وسياسة خصوصية وبيانات المتجر.

**مهم:** هذا ملف مشروع المصدر وليس APK جاهزاً. لا يمكن تثبيته مباشرة قبل تصديره من Godot.
